# Sorry, Rishita ❤️

A personal, mobile-first apology experience.

## Deploy
Import this repository into Vercel. It is a static site; no build command is required. Set the output directory to `.` if prompted.

The experience includes a passcode screen, personal apology letter, memories gallery, hold-to-fill heart, virtual gifts, ambient music controls, and replay.

Passcode is configured in `app.js`.
